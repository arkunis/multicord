# Utilisation du nom et du logo Multicord

Le **code** de Multicord est libre (licence [AGPL-3.0](LICENSE)) : vous pouvez l’utiliser, l’étudier, le modifier et le redistribuer, dans le respect de cette licence.

Le **nom** « Multicord » et son **logo** ne sont pas couverts par cette licence. Ils désignent le projet officiel publié par arkunis sur [github.com/arkunis/multicord](https://github.com/arkunis/multicord) et sur [arkunis.github.io/multicord](https://arkunis.github.io/multicord/). Cette page dit comment les utiliser, pour qu’aucune personne ne confonde une autre version avec la version officielle.

## Autorisé sans demander

- **Parler de Multicord** : articles, vidéos, tutoriels, comparatifs.
- **Héberger votre propre serveur** avec le code officiel, même pour un public, et l’appeler par exemple « Multicord de l’association X ». Vous pouvez régler les variables prévues pour cela (`INSTANCE_*`, base de données, TURN…).
- **Redistribuer l’application officielle sans la modifier**.
- **Proposer des modifications** au projet officiel (issues, pull requests).
- **Dire qu’une version est « basée sur Multicord »** ou « dérivée de Multicord ».

## Pour une version modifiée

Si vous distribuez ou hébergez pour d’autres une version dont le code a été modifié :

- donnez-lui **un autre nom** et **un autre logo**, qui ne prêtent pas à confusion avec Multicord ;
- vous pouvez indiquer qu’elle est « basée sur Multicord », avec un lien vers le projet officiel ;
- ne la présentez pas comme officielle, approuvée ou soutenue par le projet Multicord ;
- l’application de bureau ne doit pas se mettre à jour depuis les publications officielles, ni utiliser le nom « Multicord » dans son installateur.

Le lien « Soutenir le projet » fait partie de l’identité du projet officiel : une version qui le remplace par un autre lien de don est une version modifiée, et suit donc les règles ci-dessus.

## Questions

Pour un usage qui ne rentre pas dans ces cas, ouvrez une [discussion sur GitHub](https://github.com/arkunis/multicord/issues) avant de publier.
